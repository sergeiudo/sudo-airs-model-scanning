02 · The Problem

An ML model
is an unsigned executable.

A pickle file deserializes into arbitrary Python. A GGUF prompt template can inject shell commands. A HuggingFace repo can ship a Trojan in weights and a backdoor in requirements.txt. Yet most teams pull models from public registries with no inspection at all.

  • CodePickle, Keras H5, GGUF templates — all execute on load.
  • ChainCompromised deps, poisoned weights, tampered cards.
  • HiddenNeural backdoors and exfiltration channels in weights.
  • BlindNo AV equivalent. No deploy-time gate. No audit trail.

05 · Install

The SDK lives behind
an authenticated PyPI.

1
Token Exchange
POST auth.apps.paloaltonetworks.com/oauth2/access_token
  grant_type=client_credentials
↓
2
Resolve Index URL
GET api.sase.paloaltonetworks.com/aims/mgmt/v1/pypi/authenticate
  Authorization: Bearer <token>
↓
3
Install
pip install model-security-client
  --extra-index-url <short-lived url>

Why two steps? The SDK (model-security-client and its sibling airs-schemas) is proprietary — it lives on Palo Alto's private PyPI, not public PyPI. A naked pip install will fail.

Why a script? Both setup-sdk.sh and get-pypi-url.sh ship in this repo. The token and PyPI URL are short-lived, fetched fresh per install. Credentials never leave the host; only the bearer token touches our cloud.

Why it matters for enterprise: the install is reproducible inside a hardened build agent, with no human in the loop and no long-lived registry token to leak.

07 · Configuration

Policy lives in Security Groups.

One group per source type. Each group holds a set of rules — enable / disable / set blocking — that get applied to every scan from that source. Default groups are auto-created per tenant, so customers can scan on day one.

08 · The API

Three lines, then
a minute of work.

from model_security_client.api import ModelSecurityAPIClient
from uuid import UUID

client = ModelSecurityAPIClient(
    base_url="https://api.sase.paloaltonetworks.com/aims",
)

result = client.scan(
    security_group_uuid=UUID("<hf-group-uuid>"),
    model_uri="https://huggingface.co/microsoft/DialoGPT-medium",
)

# auth is implicit — SDK reads env vars
  1. Download Service pulls all files from the source URI.
  2. Catalog Identify formats: PyTorch, ONNX, SafeTensors, Pickle, GGUF…
  3. Evaluate Run every enabled rule in the selected Security Group.
  4. Aggregate Produce a single verdict: ALLOWED · BLOCKED · WARNING.
  5. Persist Full findings to SCM; summary returned to API caller.

Typical latency: 30 – 90 seconds for small/medium models · up to 15 minutes for 10 GB+ models.

11 · Integration

Bolt the verdict into
your promotion pipeline.

def validate_model_for_deployment(model_uri, security_group_uuid, blocking=True):
    result = client.scan(security_group_uuid=security_group_uuid, model_uri=model_uri)
    is_safe = str(result.eval_outcome) == 'EvalOutcome.ALLOWED'
    if not is_safe and blocking:
        sys.exit(1)   # fail the build
    return is_safe, result
